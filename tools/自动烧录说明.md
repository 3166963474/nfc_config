# CH340 自动烧录工具

该工具实时监测新插入的 CH340/CH341 串口，并调用 STM32CubeProgrammer 的命令行程序烧录固件。

## 准备

1. 安装 STM32CubeProgrammer。
2. 安装 Python 3.10 或更高版本。
3. 在工程根目录安装依赖：

```powershell
python -m pip install -r tools/requirements.txt
```

本工程工具已加入以下 CubeProgrammer 路径的自动识别：

```text
D:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\bin\STM32_Programmer_CLI.exe
```

工具按照本项目自动下载电路控制启动模式：

- DTR 使能时，芯片 BOOT 为低电平。
- RTS 使能时，芯片 NRST 为低电平。
- 烧录前自动将 BOOT 置高并产生 NRST 低脉冲，进入系统 Bootloader。
- 烧录后自动将 BOOT 置低并再次产生 NRST 低脉冲，启动用户程序。

默认复位脉宽为 100 ms，释放复位后等待 200 ms。可用 `--reset-pulse` 和 `--boot-delay` 调整；排障时可用 `--no-auto-boot` 完全关闭控制。

## 使用

单次模式：等待一个新设备，烧录一次后退出。

```powershell
python tools/auto_flash.py once "MDK-ARM/BUS_SEAT_V0_0_3/BUS_SEAT_V0_0_3.hex"
```

连续模式：每次插入设备烧录一次，拔出后再次插入可再次烧录。

```powershell
python tools/auto_flash.py continuous "MDK-ARM/BUS_SEAT_V0_0_3/BUS_SEAT_V0_0_3.hex"
```

程序启动时已经插着的 CH340 默认不会烧录，避免误操作；需要立即处理已有设备时增加 `--include-existing`。

如果 CLI 没装在默认目录，可显式指定：

```powershell
python tools/auto_flash.py once firmware.hex --cli "D:\ST\STM32CubeProgrammer\bin\STM32_Programmer_CLI.exe"
```

烧录 `.bin` 时默认地址为 `0x08000000`，可用 `--address` 修改。使用 `--dry-run` 可验证检测逻辑并只打印 CubeProgrammer 命令。完整参数可运行：

```powershell
python tools/auto_flash.py --help
```

## 说明

- CH340 使用常见 VID `1A86`，同时兼容设备描述中包含 CH340/CH341 的驱动。
- 串口会先被短暂打开并通过 DTR/RTS 执行进入 Bootloader 的时序，然后立即释放给 CubeProgrammer。
- 默认参数为 `115200, 8E1`，烧录后校验并复位。
- 连续模式中，同一个 COM 口保持连接时不会重复烧录，必须先拔出再插入。
